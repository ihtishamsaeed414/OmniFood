max-width property:
	- if the container is larger than the specified max-width then the width of the elemetn is equal the value that was specified for max width.
	- however if the container width is less than the specified max-width then the widht of the element will be 100% of the container element width.
Rem(root element which  is the HTML tag in which all other tags lies): 
	- 1 rem =16px
	- by applying the rem we ca easily change it from root(HTML) which will automatically change the all the lenghts in document  consistently.
--All the the units are converted to pixels before rendering on the browsing page which can be seen in inspect->computed
