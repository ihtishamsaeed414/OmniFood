1: all tags under one html tag
2: opening tag, content, and closing tag makes an element(elements make a webpage or website)
3: each an everything shuld be under a tag if not it will be unstructured text
4: some tags are self closing and has attributes e.g <img src = "image.jpg"/> also attribute should not have commas in between them.
5: non-self closing tag has forward slash before text(</khan>) and self closing tag has after text (<khan/>). modern html has no slash anymore in self closing tags
